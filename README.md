# LingoLab Turkish

Интерактивный лендинг курса турецкого языка.

## Файлы

- `index.html` — готовая страница сайта.
- `assets/journey-desktop.mp4` — видео третьего блока для компьютеров (`v3.mp4`).
- `assets/journey-mobile.mp4` — видео третьего блока для телефонов (`v4.mp4`).

Страница рассчитана на обычный статический хостинг. Для корректной скролл-перемотки сервер должен поддерживать HTTP Range-запросы к MP4.
